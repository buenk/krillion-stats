Bookmarklet

  1. Show the bookmarks toolbar in Firefox (Ctrl+Shift+B).
  2. Drag this button onto the toolbar: 🦐 Krillion Stats
  3. Finish the daily dive on krillion.io, click the bookmark, then click Save to stats site.

The button above loads the latest capture.js from this site each time, so fixes reach you without reinstalling. If it ever stops loading, use the self-contained version instead: 🦐 Krillion Stats (standalone)

The first run also imports your past scores from the game's local history. The field average and percentile can only be captured on the day itself, because Krillion stops serving past days' stats.

Your data

Your data lives in this browser's storage. Export it now and then to keep a backup. To show it on other devices, commit it as data.json in the repo; the site merges that file in on load.

Not affiliated with Krillion. Data comes from your own browser and the public endpoints the game's results screen uses.
